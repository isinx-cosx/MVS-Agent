按**你会看到的现象**组织。每条都写清"这是什么"、"怎么办"、"为什么会这样"。

## 启动与连接

### 界面显示「未配置模型」

**不是故障，是设计。** 没有默认供应商：没配就是未配，不会偷偷连本机 Ollama 让你以为连上了。

```powershell
node src/cli/serve.ts --profile ollama        # 或者
node src/cli/serve.ts --base-url http://127.0.0.1:8080/v1 --model qwen3.6
```

也可以在界面「设置 → 模型」里填端点、模型名、密钥。

### 浏览器 404 / 打不开

1. 服务起来了吗？启动输出里有一行 `界面  http://127.0.0.1:…/`
2. 开了令牌吗？默认要求，第一次要带 `/?token=<启动时打印的令牌>`
3. `--dev` 模式需要 Vite 在 `5173` 跑着；**没有 Vite 时界面会一直是旧的空壳** —— 这是最容易误判"改了没生效"的原因。开发阶段建议直接用普通模式：

```powershell
node src/cli/serve.ts --port 3080 --no-token
```

### 改了界面但没变化

界面是构建产物，服务端从 `web/` 读：

```powershell
npm run ui:build     # 必须重新构建
```

然后刷新（`Ctrl+F5`）。产物文件名带内容哈希，所以同名文件不会被缓存 —— 但如果 HTML 本身被缓存，仍需要强刷。

## 命令与沙箱

### 「沙箱没能启动：2」

`2` 是 `ERROR_FILE_NOT_FOUND` —— 要执行的程序找不到。历史上这是一个真 bug（把用户命令行原文当程序名），已修。若仍出现：

1. 命令的第一个词拼错了吗？
2. 该程序在 `PATH` 里吗？（沙箱不继承一些环境变量，见下条）

### 沙箱里「不是内部或外部命令」

容器**不能枚举没有授权的目录**，所以 `cmd` 无法在 `C:\Program Files\nodejs` 里搜索 `node.exe`。用一次管理员授权解决：

```powershell
npm run sandbox:grant -- .
```

`git` / `npm` / `npx` / `pnpm` / `yarn` 不需要这条 —— 它们按设计跑在沙箱外。

### `dir` 报「拒绝访问」，但 `type` 能读文件

`cmd` 的 `dir` 要读**卷信息**，容器里可能被拒。替代：

```
for %f in (*) do @echo %f
```

或者让工具自己列目录（`glob`）。

### `git` 报 `could not open '/dev/null'`

Git for Windows 的 MSYS2 运行时在容器内起不来 —— 那是设备对象，ACL 补不了。所以 `git` 直接出沙箱（结果标 `sandbox: off-tool`）。如果你关掉了放行名单，就需要 `MVS_SANDBOX=off`。

## 模型与上下文

### 「上下文即将超出」

估算已经到预算的 90%，接下来会压缩。压缩是两级的：先丢旧工具输出，再摘要早期对话。

想少压缩：把 `contextWindow` 设成真实值（llama.cpp 可以用 `--ctx-size` 对一下），或者开新会话。

### 回答里出现 `〔输出审核：… 已打码〕`

读到/抓到的内容命中敏感规则，被打了码再交给模型。分项在括号里：密钥类、私密内容、编码/分段判据。

如果这段内容你确实需要模型看见原文，用一次性代码：

```powershell
npm run reveal:code          # 生成 6 位代码，5 分钟有效，用一次即焚
```

### 「tainted_path：… 的内容曾经被扣留过」

这个文件被打码过，模型没看过原文 —— 直接改会把打码串写回文件。三个出口：

1. `reveal:code`（临时让它看见一次）
2. CLI 里解除限制
3. 你自己改，然后让模型继续

**注意**：提示语里如果写的是「这一条没有记入 taint，改动不受此条保护」，那是**如实说明**（`grep` 来源、编码判据这类记不了 taint），不是故障。

## 会话与撤销

### 点「新会话」却跳进了旁边的对话

历史 bug（`null` 有歧义）。现在已修：点「+」停在空状态，发出第一条消息才真正创建。如果你还看到旧行为，那是浏览器里的旧产物 —— 强刷。

### 撤销之后文件没回来

1. 确认撤销的是**事务**而不是单条改动
2. 被删文件的恢复受 `MVS_RESTORE_DELETED` 控制
3. 快照有 TTL，过期就没了（`npm run maintain` 会清）

### 后台任务在哪看

输入框上方的顶部栏「后台任务 N」，点开是命令列表；每条命令的完整输出在它对应的工具卡里。终止用 `kill_job`，或者在工具卡里操作。

## 性能

### 本地引擎很慢

单槽位是硬件事实：一台机器同时只能跑一个生成。开子 Agent **买的是上下文隔离，不是并行** —— 它会排队。

### 首次响应很久

可能是模型窗口在探测（`/v1/models`、`/api/show`、`/props` 三个策略依次尝试）。探测失败会退回保守默认，启动输出里会写「来源：保守默认」。

## 还是不行

收集这三样再问：

1. 启动输出的前 20 行（模型、模式、窗口、端点）
2. 出问题那条工具调用的完整卡片（展开后的参数与输出）
3. `npm test` 与本仓库 `node tools/check-tools.mjs` 的结果

如果怀疑是文件权限问题，先跑：

```powershell
icacls <出问题的目录>
```

本仓库对"没验过就下结论"是有戒心的 —— 带上证据比带上描述有用得多。
