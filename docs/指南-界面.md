# 指南：界面

界面是一页 React（`ui/`），构建产物在 `web/`。这一篇按**你看到的顺序**讲：从上到下、从左到右。

---

## 整体布局

```
┌───────────────┬──────────────────────────────────────────────┐
│  MVS Agent    │  对话名            子 Agent 2  后台任务 1    │ ← 顶部栏
│               ├──────────────────────────────────────────────┤
│  工作区        │                                              │
│   Venture-main│  你：帮我看看这个函数为什么慢                  │ ← 用户气泡（右）
│   MVS Agent   │                                              │
│               │  ▸ 已思考并执行命令 · 18.4 秒 · 5 次工具调用   │ ← 执行过程（折叠）
│  改动          │                                              │
│               │  这个函数的问题在于……                          │ ← 正式回答
│               │  ⧉                                            │ ← 复制
│               ├──────────────────────────────────────────────┤
│  设置          │  ┌──────────────────────────────────────┐    │
│               │  │ 说点什么…                        (↑) │    │ ← 输入框
│               │  └──────────────────────────────────────┘    │
│               │    权限 · 可改工作区    qwen3.6               │
│               │       上下文 372 / 32,768 (1%)                │
└───────────────┴──────────────────────────────────────────────┘
```

---

## 左栏

**工作区树。** 每个工作区下面的数字是未读/进行中的会话数；`+` 在这个工作区下新建对话，`×` 从列表移除（不会删文件）。

**改动。** 这一轮里被改过的文件，点进去可以逐条撤销。撤销是**事务级**的：一次工具调用的全部改动一起回滚，不会只回滚一半。

**设置。** 主题、字号、渲染开关、模型、技能、插件。

---

## 对话区

### 用户消息

靠右的气泡。内容原样保留换行与缩进 —— 多行输入不会被压成一段。

### 执行过程

一轮**只有一个**折叠块。展开后按发生顺序排列：

```
▾ 已思考并执行命令 · 18.4 秒 · 5 次工具调用
  ├ ▾ 思考：先看看这个函数被谁调用……
  ├   ▸ grep  getUser
  ├   ▸ read_file src/user.ts
  ├ ▾ 思考：原来是每次循环都查一次库……
  ├   ▸ edit src/user.ts
  └   ▸ run_command npm test · 退出码 0
```

- **正在跑**：全展开，且不能收起（免得看不见它在做什么）
- **跑完**：收成一行摘要，点一下重新展开
- **被打断**：摘要写「已打断 · 已思考并执行命令」，不写「已完成」

摘要里的时长是**从你发出消息到模型给出正式回答**的总时长，不是两段思考之间的间隔。

### 工具调用

一行一条，鼠标移上去才浮出底色。点一下展开参数与输出。

```
▸ read_file   读取 src/host/session.ts
```

调用的那一刻它就出现，摘要先显示「执行中…」，结果回来之后换成真正的摘要。

### 正式回答

Markdown 渲染：代码高亮、表格、数学公式、图片（图片默认不自动加载，可在设置里开）。

左下角那枚图标是**复制**：复制的是 Markdown 原文，不是屏幕上的渲染结果 —— 粘到别处时代码块的语言标记、缩进都还在。

### 顶部栏

| 显示 | 含义 |
|---|---|
| 对话名 | 太长会截断，悬停看全名 |
| 子 Agent N | 这条对话里调用过几次 `spawn_agent` |
| 后台任务 N | 可点开，逐条列出后台命令 |
| 已拦下 N | **只在真有命中时出现**；悬停看分项（密钥/隐私/编码/片段/分段/扣留） |

## 输入区

```
┌────────────────────────────────────┐
│ 说点什么…                     (↑)  │
└────────────────────────────────────┘
   权限 · 可改工作区    qwen3.6
     上下文 372 / 32,768 (1%) · 速度 · 缓存
```

- **输入框**：`Enter` 发送，`Shift+Enter` 换行；高度随内容长到上限（`26vh`）后内部滚动
- **权限**：这个会话的权限上限，改它只影响当前会话
- **模型**：这个会话用哪个模型，跨供应商可选
- **指标行**：上下文占用、生成速度、缓存命中 —— 它是「读」的信息，不属于输入，所以在卡片外

空会话时，输入框会跟着图标和标语一起居中；发出第一条消息后回到底部。

---

## 空状态

新建对话后看到的是：品牌图形 + 一句会每 30 秒换一次的标语 + 居中的输入框。

标语不是装饰 —— 它写的是这个工具在意的东西（"卡住了我会告诉你卡在哪，而不是不吭声"）。你在它下面说第一句话，对话才算真正开始。

## 设置页

| 分组 | 有什么 |
|---|---|
| 外观 | 主题（浅色/深色/跟随系统）、正文字号 |
| 渲染 | 代码高亮、数学公式、图片自动加载 |
| 模型 | 端点、模型名、密钥（显示打码尾巴）、上下文窗口 |
| 技能 | 列出工作区里的技能，逐个审批与启停 |
| 插件 | 同上；插件的界面部分还在做 |

---

## 已知的界面限制

- **流式生成中不显示复制按钮** —— 那时文本还在变，复制半截没有意义
- **`dir` 在沙箱里会被拒**（`cmd` 要读卷信息），要列目录用 `for %f in (*) do @echo %f` 或让工具自己读
- 界面只做「能列出、能审批、能启停」的插件支持，插件的面板/入口/状态展示还在设计（见 [`技能与插件设计.md`](技能与插件设计.md)）
