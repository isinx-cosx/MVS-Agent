# 指南：沙箱与权限

这一篇讲**它到底挡得住什么、挡不住什么**，以及为什么这么设计。想要"能跑就先跑"的路径，看 [快速开始](指南-快速开始.md)。

---

## 三层边界，各管一段

```
你的指令
  ↓
① 权限模式     —— 这个会话允许做什么（只读 / 可改工作区 / 完全放行）
  ↓
② 路径与内容校验 —— 目标必须在工作区内；内容过输出审核（密钥、隐私、编码绕过）
  ↓
③ 沙箱         —— 命令在 AppContainer 里跑：断网、只写工作区、限进程与内存
```

三层**互不替代**。前两层挡"不该做的事"，第三层挡"该做的事被做过头"。

---

## 沙箱做了什么

`src/sandbox/appcontainer.ts` 给沙箱建一个**专属 SID** 的 AppContainer：

- **断网**：不给任何网络能力（要联网必须显式 `MVS_SANDBOX_NET=1`）
- **只写工作区**：工作区加可写 ACE，其它位置没有
- **资源上限**：Job 对象限进程数、内存、写字节
- **句柄隔离**：只继承 stdout/stderr 两个句柄（用 `PROC_THREAD_ATTRIBUTE_HANDLE_LIST`）

文件读写**都走同一套授权**：新机器第一次要跑一次（管理员）

```powershell
npm run sandbox:grant -- .
```

它给工作区加可写、给祖先链加"穿过"、给 `C:\Program Files\nodejs` 只读可执行。

---

## 谁不在沙箱里

`git` / `npm` / `npx` / `pnpm` / `yarn` 按设计**跑在沙箱外**：

- `git` 是 Git for Windows 的 MSYS2 运行时，启动时打开 `/dev/null` 被拒（那是**设备对象**，不是文件，ACL 补不了）
- `npm` 要 `realpathSync('C:\')`，需要盘根读属性；而把那条 ACE 加在 `C:\` 上会打断 esbuild 的目录遍历（实测）

它们出的不是"任意命令"，是一份**固定名单**；出沙箱之后仍受 Job 上限与 kill-tree 管，结果里标 `sandbox: off-tool` 并附原因。

## 挡不住什么（实测，不是推测）

| 东西 | 状态 |
|---|---|
| 注册表读取 | **挡不住**（实测能读 HKLM） |
| 剪贴板 | **挡不住**（PowerShell 读剪贴板抛的是 `ExternalException`，不是拒绝访问） |
| 命名管道 | **挡不住**（能连已有管道） |
| 目录联结 / 符号链接 | 删除类工具做了检查，但从命令里 `mklink` 仍可能绕过 |
| 网络（当 `MVS_SANDBOX_NET=1`） | 退回受限令牌 + Job，断网能力没了 |
| 磁盘配额 | **做不到**（`fsutil quota` 无法给 AppContainer SID 建配额，错误 1332），改用卷余量哨兵 |

完整清单（含证据等级）见 [`挡不住清单.md`](挡不住清单.md)。

## 输出审核挡什么

它挡的是「模型**知道**」，不是「进程**外发**」。

- 密钥类（`sk-`、`AKIA`、`ghp_` 等前缀）→ 打码
- 隐私类（邮箱、手机号、身份证等）→ 打码
- 编码绕过（base64 / hex / URL 编码，最多解三层）
- 分段绕过（一个 token 被拆到多次读取里；按切片累积判断）
- 二进制/图片：不把内容交给模型，只给元信息

**被打码过的路径会记入 taint**：模型没看过原文，就不许按"原文"去改它（否则打码串会被写回文件，真值永久丢失）。要改，用 `npm run reveal:code` 生成一次性代码，或者在 CLI 里解除。

⚠️ 但要注意：**taint 不是保险箱**。`grep` 的结果里如果出现敏感内容，来源是目录而不是具体文件，那种情况记不了 taint —— 提示语里会明说「这一条没有记入 taint」，不会假装记了。

## 网络

默认**只在模型调用时联网**（打你的模型端点）。工具侧：

- 沙箱内默认断网
- `MVS_ALLOW_NET=npm,pip` 可以按词放行（例如让 `npm install` 能出去）
- `web_search` / `web_fetch` 走的是主进程的网络，不受沙箱断网影响

**已知结构缺口**：`web_fetch` 没有 host 白名单，配合 `run_command` 的完整 shell，理论上存在把数据送出去的通道。设计上更倾向"默认关网络 + 显式开关"，而不是写一张必然漏的白名单 —— 这一条还没落地，见 [`待办与紧急度.md`](待办与紧急度.md)。

## 可逆性

每一次**变更型**工具调用前后，恢复层对整棵树拍快照（含 NTFS 备用数据流）。撤销是事务级的：

```powershell
npm run recovery list
npm run recovery revert <txnId>
```

界面里在左栏「改动」点进去撤销。被删的文件默认也恢复（`MVS_RESTORE_DELETED`）。

快照有 TTL 与数量上限，`npm run maintain` 会清过期项。

## 关掉沙箱

```powershell
$env:MVS_SANDBOX = 'off'
node src/cli/serve.ts --port 3080
```

关掉之后 `run_command` **不再受范围限制** —— 权限模式与路径校验还在，第三层没有了。什么时候合理：这台机器是你独占的开发机、且你在做需要完整工具链的事。什么时候不合理：有别的账户、或你准备跑不认识的代码。
