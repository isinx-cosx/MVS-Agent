## 2025 年 · 界面重构与三处静默失效

这一轮的主线是**界面从可用变成能看**，以及**三处"说了没做"的地方被修掉**。

### 一、界面（`ui/`）

| 改动 | 说明 |
|---|---|
| 空会话的输入框 | 空状态时输入框跟图标、标语一起居中；发出第一条消息后回到底部。同一个元素只渲染一次，靠父容器切换位置，不复制两份 JSX |
| 对话顶部栏 | 新增：对话名 / 子 Agent 数 / 后台任务数（可展开看是哪几条命令）/ 审核命中数（**只在真有命中时出现**） |
| 执行过程折叠 | 一轮一个折叠块，**按发生顺序**排列「思考 → 工具调用 → 思考 → …」，跑的时候全展开、跑完收成一行摘要（`已思考并执行命令 · 12.3 秒 · 5 次工具调用`），被打断写「已打断」 |
| 工具调用 | 从卡片改成**一行横条**，hover 才浮出底色；调用的那一刻就出现（`tool_intent` 到达时立刻拉一次投影） |
| 用户消息 | 从左侧细轨改成**右侧气泡** |
| 回答复制 | 每段回答左下角一枚图标按钮（复制 → 对勾），复制 Markdown 原文 |
| 配色与排版 | 换回 DSH 那套纯中性（纯白底、`oklch` 灰阶）；正文列与输入框共用 `--col` 一个宽度变量 |
| 输入框 | 卡片只包住「输入行 + 两个下拉」，不再画边框，去掉多层的焦点光环 |

### 二、后端

| 修复 | 位置 | 说明 |
|---|---|---|
| `沙箱没能启动：2` | `src/tools/command-tool.ts` | 沙箱分支把**用户输入的原文**当可执行文件传给 `CreateProcessW` → `ERROR_FILE_NOT_FOUND(2)`。只有显式带 `args` 的调用才碰巧走对。改用解析后的 `file`/`argv`，并把解析提到沙箱分支之前 |
| `cmd /c` 引号 | `tools/sandbox-net-run.mjs` | 原来给每个参数都套双引号，`cmd` 对 `/c` 后的引号有自己的剥离规则 → `'"echo hi' 不是内部或外部命令`。改成只在需要时加引号 |
| 沙箱内找不到 `node` | `src/cli/sandbox-grant.ts` | `icacls` 的 traverse 写成 `:X`（无效参数，静默失败），正确是 `(X)`；并补上祖先链（含 `C:\Program Files`、盘根） |
| 开发工具出沙箱 | `src/tools/command-tool.ts` | `git` / `npm` / `npx` / `pnpm` / `yarn` 按设计**跑在沙箱外**（MSYS 要设备对象、npm 要盘根读属性），但仍受 Job 上限与 kill-tree 管，结果标 `sandbox: off-tool` 并附一句原因 |
| 默认供应商 | `src/config/resolve.ts` | 去掉 `?? 'ollama'` 兜底：没配就是**未配置**，不再悄悄连本机 Ollama（"没配"与"配了"在界面上长得一样） |
| **taint 假承诺** | `src/host/session.ts` | 记录是三重条件（有 taint 注入 / 有路径 / 是 `read_file`），提示语却是无条件的 —— `grep` 来源、编码/分段判据、无 taint 注入三种情况都会说"已记入 taint，改动会被拒绝"。现在提示语跟着事实走，没记就明说没记 |

### 已知仍不闭合

- `git --version` 在沙箱内起不来（MSYS 运行时打开 `/dev/null` 被拒）—— 这是出沙箱的原因，不是待修项。
- 网络出站仍未默认关闭：`web-tools.ts` 裸 `fetch` + `run_command` 完整 shell = 数据外送通道，输出审核设计上不管这一段。
- taint 不区分「形态」与「值」：安全文档里示例用的 `sk-` 前缀也会触发打码并 taint，导致审计类任务改不了文档。
