<p>⚠️ <strong>SECURITY WARNING:</strong> Auto-approve settings bypass confirmation prompts, giving Roo direct access to your system. <h2 class="anchor anchorTargetStickyNavbar_ZB1J" id="quick-start-guide">Quick Start Guide<a href="#quick-start-guide" class="hash-link" aria-label="Direct link to Quick Start Guide" title="Direct link to Quick Start Guide" translate="no">​</a></h2>
<ol>
<li class="">Open the Auto-Approve dropdown next to the chat input</li>
<li class="">Toggle &quot;Enabled&quot; at the bottom-right of the dropdown to activate or pause auto-approval</li>
<li class="">Use the All/None chips to bulk-select or clear permissions, or select individual tiles; you can keep Enabled On with &quot;None&quot; selected</li>
<li class="">(Optional) Click the gear icon to open Settings for deeper per-permission controls</li>
</ol>
<h3 class="anchor anchorTargetStickyNavbar_ZB1J" id="keyboard-shortcut-and-command-palette">Keyboard Shortcut and Command Palette<a href="#keyboard-shortcut-and-command-palette" class="hash-link" aria-label="Direct link to Keyboard Shortcut and Command Palette" title="Direct link to Keyboard Shortcut and Command Palette" translate="no">​</a></h3>
<p><strong>Default shortcut:</strong> <code>Cmd+Alt+A</code> (macOS) / <code>Ctrl+Alt+A</code> (Windows/Linux)</p>
<p><strong>Command Palette:</strong> <code>roo-cline.toggleAutoApprove</code></p>
<p>Quickly toggle auto-approve on/off without using the mouse. Both the keyboard shortcut and the Command Palette command toggle the global &quot;Enabled&quot; state while preserving your permission selections.</p>
<p><strong>Via Command Palette:</strong></p>
<ol>
<li class="">Open the Command Palette (<code>Cmd+Shift+P</code> / <code>Ctrl+Shift+P</code>)</li>
<li class="">Type &quot;Toggle Auto-Approve&quot; or search for <code>roo-cline.toggleAutoApprove</code></li>
<li class="">Press Enter to toggle the auto-approve state</li>
</ol>
<p><strong>To customize the shortcut:</strong></p>
<ol>
<li class="">Open VS Code Command Palette (<code>Cmd+Shift+P</code> / <code>Ctrl+Shift+P</code>)</li>
<li class="">Search for &quot;Preferences: Open Keyboard Shortcuts&quot;</li>
<li class="">Search for the command name (varies by language):<!-- -->
<ul>
<li class="">English: &quot;Toggle Auto-Approve&quot;</li>
<li class="">Other languages: Look for the localized equivalent</li>
</ul>
</li>
<li class="">Click the pencil icon next to the command</li>
<li class="">Press your desired key combination</li>
<li class="">Press Enter to save</li>
</ol>
<p><strong>Note:</strong> The command name appears in your VS Code interface language. If you&#x27;re using a non-English locale, the command will be translated accordingly.</p>

<h4 class="anchor anchorTargetStickyNavbar_ZB1J" id="important-behaviors">Important behaviors<a href="#important-behaviors" class="hash-link" aria-label="Direct link to Important behaviors" title="Direct link to Important behaviors" translate="no">​</a></h4>

<h3 class="anchor anchorTargetStickyNavbar_ZB1J" id="command-execution">Command Execution<a href="#command-execution" class="hash-link" aria-label="Direct link to Command Execution" title="Direct link to Command Execution" translate="no">​</a></h3>
<div class="theme-admonition theme-admonition-caution admonition_usjr alert alert--warning"><div class="admonitionHeading_u4Cr"><span class="admonitionIcon_msdS"><svg viewBox="0 0 16 16"><path fill-rule="evenodd" d="M8.893 1.5c-.183-.31-.52-.5-.887-.5s-.703.19-.886.5L.138 13.499a.98.98 0 0 0 0 1.001c.193.31.53.501.886.501h13.964c.367 0 .704-.19.877-.5a1.03 1.03 0 0 0 .01-1.002L8.893 1.5zm.133 11.497H6.987v-2.003h2.039v2.003zm0-3.004H6.987V5.987h2.039v4.006z"></path></svg></span>Command Execution (Risk: High)</div><div class="admonitionContent_m16x"><img src="/img/auto-approving-actions/auto-approving-actions-18.png" alt="Command execution setting with whitelist interface" width="550"><p><strong>Setting:</strong> &quot;Always approve allowed execute operations&quot;</p><p><strong>Description:</strong> &quot;Automatically execute allowed terminal commands without requiring approval&quot;</p><p><strong>Command management:</strong> &quot;Command prefixes that can be auto-executed when &#x27;Always approve execute operations&#x27; is enabled. Add * to allow all commands (use with caution).&quot;</p><p><strong>Risk level:</strong> High</p><p>This setting allows terminal command execution with controls. Use an allowlist and a denylist together for defense-in-depth.</p><ul>
<li class="">Precedence: Deny rules take precedence when their matching prefix is equally or more specific than the allow match (longest-prefix wins).</li>
<li class="">High-risk commands to deny by default:<!-- -->
<ul>
<li class="">Unix/macOS: rm, sudo, dd, mkfs, diskutil eraseDisk, shutdown, reboot, chmod -R, chown -R, kill -9, curl | sh, wget | sh</li>
<li class="">Git/Package: git push, npm publish, yarn publish, pnpm publish</li>
<li class="">Windows/PowerShell: Remove-Item, Format-Volume, Stop-Process, shutdown, Set-ExecutionPolicy</li>
</ul>
</li>
<li class="">Production template:<!-- -->
<ul>
<li class="">Deny all with &quot;*&quot; then allow specific safe prefixes like &quot;git&quot;, &quot;npm run&quot;, &quot;echo&quot;.</li>
</ul>
</li>
<li class="">Dangerous substitution guard: Even allowed prefixes won’t auto-approve if the command contains dangerous parameter or process substitutions (e.g., <code>${var@P}</code>, subshells inserted into here-strings, zsh process substitution <code>=(...)</code>, zsh glob qualifiers with <code>e:...:</code>).</li>
</ul><p>Configuration</p><ul>
<li class="">UI (recommended): Settings → Auto‑Approve → Execute → use &quot;Allowed Commands&quot; and &quot;Denied Commands&quot; editors to add/remove prefixes.</li>
